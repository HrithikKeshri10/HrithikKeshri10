### 📱 Featured Projects

*   **DriveSafe:** A React Native (Expo) app that scores driving safety in real time from a phone's motion sensors — reads 4 sensors at 20 Hz to detect 6 unsafe driving behaviors (harsh braking, sharp turns, phone handling, and more) and rates each trip 0–100. Features live sensor visualizations (G-force pad, acceleration trace), a simulation mode for testing without driving, and local trip history via AsyncStorage.
*   **Fork & Go:** A React Native (Expo) food-delivery app spanning 10 screens, built around a layered navigation architecture (drawer → bottom tabs → per-tab stacks). Implements a persistent login flow, React Context for cart and auth state, deep linking into any restaurant, and a full browse → cart → order flow — focused on client-side navigation and state (mock auth, local data).
*   **High-Performance Social Media Backend:** Built with Go and Fiber, featuring 11 RESTful endpoints, a real-time notification system using goroutines/channels, and Redis caching with automatic invalidation to reduce database load.
